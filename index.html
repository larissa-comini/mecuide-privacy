Política de Privacidade

Última atualização: Setembro de 2026.

O aplicativo Me Cuido respeita sua privacidade e está comprometido em proteger seus dados pessoais e informações de saúde.

Dados coletados

Podemos coletar informações fornecidas voluntariamente pelo usuário, incluindo:

  • Nome;
  • E-mail;
  • Informações de login;
  • Foto de perfil;
  • Dados pessoais cadastrados no perfil, como data de nascimento, telefone e outras informações informadas pelo usuário;
  • Informações relacionadas à saúde, como sintomas, consultas, exames, medicamentos, lembretes, histórico, internações, vacinas, controles e pendências;
  • Documentos enviados pelo usuário, incluindo imagens ou arquivos PDF;
  • Carteirinha do plano de saúde enviada pelo usuário, incluindo imagem ou PDF;
  • Dados de familiares ou pessoas cuidadas cadastradas voluntariamente no aplicativo;
  • Códigos de médico ou clínica utilizados para liberação de benefícios no aplicativo.

Como utilizamos os dados

Os dados são utilizados para:

  • Permitir o funcionamento do aplicativo;
  • Criar e manter a conta do usuário;
  • Salvar e organizar informações de saúde;
  • Sincronizar dados entre dispositivos;
  • Permitir o acompanhamento de consultas, exames, medicamentos e demais registros;
  • Exibir documentos, carteirinhas e arquivos enviados pelo usuário;
  • Permitir recursos de compartilhamento familiar ou com profissionais de saúde, quando ativados pelo usuário;
  • Validar códigos de médico, clínica ou benefício;
  • Personalizar a experiência do usuário;
  • Melhorar continuamente o aplicativo.

Compartilhamento de dados

Não vendemos dados pessoais.

Os dados poderão ser compartilhados apenas nas seguintes situações:

  • Com provedores de infraestrutura necessários para o funcionamento do aplicativo, como serviços de banco de dados, autenticação e armazenamento de arquivos;
  • Com familiares, cuidadores ou pessoas autorizadas pelo próprio usuário dentro do aplicativo;
  • Com médicos, clínicas ou profissionais de saúde quando o usuário utilizar recursos de compartilhamento ou códigos vinculados a esses profissionais;
  • Quando necessário para cumprir obrigações legais ou solicitações válidas de autoridades competentes.

Infraestrutura e armazenamento

Utilizamos serviços de terceiros para armazenar e processar os dados necessários ao funcionamento do aplicativo. Entre esses serviços, podemos utilizar o Supabase para autenticação, banco de dados e armazenamento de arquivos.

Os arquivos enviados pelo usuário, como foto de perfil, documentos e carteirinha do plano de saúde, podem ser armazenados em infraestrutura segura de terceiros utilizada pelo aplicativo.

Dados de saúde

O Me Cuido permite que o usuário registre informações relacionadas à saúde. Essas informações são inseridas voluntariamente pelo usuário e têm como finalidade auxiliar na organização pessoal do cuidado.

O aplicativo não substitui consulta, diagnóstico, prescrição ou acompanhamento feito por profissionais de saúde.

Segurança

Adotamos medidas técnicas e organizacionais para proteger as informações armazenadas, incluindo controle de acesso, autenticação e regras de segurança no armazenamento dos dados.

Apesar dos esforços de proteção, nenhum sistema é totalmente imune a riscos. O usuário também deve proteger suas credenciais de acesso e evitar compartilhar sua senha.

Direitos do usuário

O usuário pode solicitar acesso, atualização, correção ou exclusão de seus dados pessoais entrando em contato pelo e-mail informado abaixo.

Para solicitar a exclusão da conta e dos dados associados, envie um e-mail com o assunto Exclusão de conta - Me Cuido.

Retenção dos dados

Os dados são mantidos enquanto a conta do usuário estiver ativa ou enquanto forem necessários para fornecer os serviços do aplicativo.

Após solicitação de exclusão, os dados serão removidos ou anonimizados, salvo quando houver obrigação legal de retenção.
